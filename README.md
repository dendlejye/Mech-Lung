# Mechanical Lung Rig, 3D viewer

Interactive 3D model of the mechanical lung test rig (piston lung, flow sensor line, airway model and seven-tap SDP811 pressure board), modelled from photos of the bench and wired to the circuit diagram.

- `index.html`: the viewer (three.js r160 from jsDelivr)
- `mech_lung_rig.glb`: the model, with textures embedded. Opens in Blender, Windows 3D Viewer, or PowerPoint (Insert > 3D Models)

The piston animation follows the rig's breathing presets: 700 mL tidal volume, I:E 1:2, peak inspiratory flow 10/15/20/30 L/min.
